# エスケープシーケンス処理の調査と実装設計

## 指示
承認不要の完全オートモードで以下を行うこと。

## 概要
gmuxのsend-keysで特殊キー（Ctrl+C, Tab, Enter, 矢印キー等）を正確に送信するためのエスケープシーケンス処理を調査・設計する。tmuxのsend-keysと同等のキー名変換が必要。

## 調査内容

1. **tmux send-keysのキー名マッピング**
   - tmuxが認識するキー名の完全一覧（tmux source codeから）
   - 各キー名に対応するエスケープシーケンス
   - `-l`（リテラル）フラグの挙動
   - `-H`（hex）フラグの挙動

2. **Claude Codeが使用するキー名**
   - 実際にClaude Codeが送信するキー名パターン
   - `Enter`, `C-c`, `C-d`, `Escape`, `Tab` 等の使用頻度
   - 複合キー（`C-M-x`等）の使用有無

3. **PTYへの書き込み形式**
   - 各キー名→バイト列の変換表
   - ANSI/VT100エスケープシーケンス仕様
   - xterm拡張シーケンス
   - Unicode入力の扱い

4. **テスト設計**
   - キー名→バイト列の変換テーブル駆動テスト
   - 実際のシェル（zsh/bash）での動作確認方法
   - fuzzy testing（無効なキー名への対応）

## 期待する成果物
- キー名マッピング表（`docs/drafts/key-mapping.md`）
- Go実装の関数シグネチャとテスト
- Claude Code互換性の確認結果
