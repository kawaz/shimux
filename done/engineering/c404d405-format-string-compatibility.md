# tmuxフォーマット文字列の互換実装

## 指示
承認不要の完全オートモードで以下を行うこと。
この指示による新規ドキュメント作成は `docs/drafts/` 配下に限定。既存ファイル編集・コード新規作成は通常通り。

## 概要
tmuxの `-F` フラグで使用されるフォーマット文字列（`#{pane_id}`, `#{pane_pid}` 等）をgmuxで再現する。Claude Codeが `-P -F "#{pane_id}"` でペインIDを取得するため、この互換性は必須。

## 設計・実装項目

1. **Claude Codeが使用するフォーマット変数の特定**
   - `#{pane_id}` — 最重要、`%N` 形式
   - `#{pane_pid}` — ペイン内プロセスのPID
   - `#{pane_tty}` — PTYデバイスパス
   - `#{pane_width}`, `#{pane_height}` — ペインサイズ
   - `#{session_name}` — セッション名
   - その他Claude Codeソース内で使われているもの

2. **フォーマットパーサー実装**
   - `#{...}` パターンのパース
   - ネストや条件式（`#{?...,...,...}`）の対応要否
   - 未知の変数への対応（空文字 or エラー）
   - テンプレートエンジン的な実装 vs 単純な文字列置換

3. **各変数の値取得**
   - `pane_id`: gmux内部のID管理から取得
   - `pane_pid`: gmux-agentが管理する子プロセスPID
   - `pane_tty`: 内部PTYのデバイスパス
   - サイズ系: `TIOCGWINSZ` から取得

4. **テスト設計**
   - 単一変数の置換テスト
   - 複数変数を含むフォーマット文字列のテスト
   - Claude Codeが実際に使用するフォーマット文字列でのE2Eテスト
   - 不正なフォーマット文字列の処理テスト
