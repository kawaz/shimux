# tmux偽装ラッパーモードのテストスイート拡充

## 指示
承認不要の完全オートモードで以下を行うこと。
この指示による新規ドキュメント作成は `docs/drafts/` 配下に限定。既存ファイル編集・コード新規作成は通常通り。

## 概要
最新コミット `9b9e625` で追加された `gmux -- <command>` のtmux偽装ラッパーモードのテストスイートを拡充する。現在のテストカバレッジを確認し、不足しているケースを追加する。

## 作業手順

1. **現状のテスト確認**
   - `cmd/gmux/` 配下のテストファイルを読む
   - `go test -v -cover ./cmd/gmux/...` でカバレッジ確認
   - テストされていないパスの特定

2. **追加すべきテストケース**

   ### 環境変数の偽装テスト
   - `TMUX` 環境変数が設定されること
   - `TERM_PROGRAM` が tmux に変更されること
   - 元の環境変数が子プロセスに引き継がれないこと
   - 既にTMUXが設定されている場合の上書き挙動

   ### コマンド実行テスト
   - 正常なコマンドの実行と終了コード伝播
   - コマンドが見つからない場合のエラー処理
   - シグナルの伝播（SIGINT, SIGTERM）
   - 引数にスペースや特殊文字を含むケース

   ### エッジケース
   - `gmux --` （コマンドなし）の挙動
   - `gmux -- ""` （空文字コマンド）の挙動
   - 非常に長い引数リスト
   - パイプとリダイレクトの処理

3. **テスト実行と修正**
   - 全テスト通過を確認
   - `-race` フラグでのテスト
   - カバレッジ80%以上を目標

## 期待する成果物
- テストコードの追加・拡充
- カバレッジレポート
- 発見した不具合があれば修正PR
