# Claude Code tmux使用パターンの深掘り調査

## 指示
承認不要の完全オートモードで以下を行うこと。高度な調査タスク。

## 概要
Claude CodeがAgent Teams機能でtmuxをどのように使用しているかを、公開情報・ソースコード・実際の動作ログから深掘り調査する。gmuxが完全互換を達成するための要件を明確化する。

## 調査項目

1. **tmuxコマンド呼び出しの全パターン**
   - WebSearchでClaude Codeのtmux関連のソースコード・ドキュメントを調査
   - 各コマンドの引数パターンを網羅的にリスト化
   - 出力のパースに使用している正規表現やフォーマット文字列を特定

2. **セッション管理の詳細**
   - セッション名の生成ルール（`{repoName}_worktree-{worktreeName}`）の確認
   - セッション作成・破棄のタイミング
   - 既存セッションの検出方法（`has-session`）

3. **ペインID体系**
   - `%0`, `%1` 等のペインID割り当てルール
   - `-t %N` 形式での指定
   - `-P -F "#{pane_id}"` での新ペインID取得

4. **エラーハンドリング**
   - tmuxコマンド失敗時のClaude Codeの挙動
   - リトライ戦略
   - ペインが消えた場合の回復動作

5. **タイミング・順序制約**
   - split-windowからsend-keysまでの最小待ち時間
   - 複数ペインの同時操作パターン
   - kill-pane後の後続コマンドの挙動

## 期待する成果物
- tmux使用パターン完全リスト
- gmux互換性チェックリスト（個別テストケース対応）
- 未対応パターンの洗い出しとgmux設計への影響分析
