# capture-pane実装方針の調査と設計

## 指示
承認不要の完全オートモードで以下を行うこと。高度な調査タスク。

## 概要
tmuxの`capture-pane`コマンドをgmuxで実現する方法を調査・設計する。PTYプロキシアーキテクチャでのターミナル画面内容のキャプチャ方法を検討する。

## 調査内容

1. **tmux capture-paneの挙動**
   - `-p`（stdout出力）, `-t`（ペイン指定）, `-S`（開始行）, `-E`（終了行）
   - スクロールバックバッファの取得
   - ANSIカラーコードの扱い（`-e`フラグ）
   - Claude Codeがcapture-paneをどう使っているか

2. **PTYプロキシでの実現方法**
   - 方法A: PTY出力をリングバッファに蓄積して返却
   - 方法B: 仮想ターミナルエミュレータ（vterm）で画面状態を保持
   - 方法C: `/dev/pts` からの直接読み取り（可能？）
   - 各方法の利点・欠点比較

3. **仮想ターミナルの実装検討**
   - Goのvtermライブラリ調査（github.com/hinshun/vt10x等）
   - 画面サイズの管理（TIOCGWINSZ/TIOCSWINSZ）
   - ANSIエスケープシーケンスの解釈
   - パフォーマンスへの影響

4. **Claude Code互換性**
   - capture-paneの出力形式の正確な再現
   - 行末の空白処理
   - エスケープシーケンス付きの出力
