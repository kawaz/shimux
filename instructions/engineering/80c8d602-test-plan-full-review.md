# テスト計画のfull-review

## 指示
承認不要の完全オートモードで以下を行うこと。/itumono-full-review を使用すること。

## 概要
`docs/test-plan.md`（約1150行）のテスト計画に対してマルチペルソナによるfull-reviewを実施する。

## レビュー観点

1. **QAエンジニア視点**
   - テストケースの網羅性（境界値、異常系、組み合わせ）
   - テスト優先度の妥当性
   - テスト実行の再現性
   - 自動化可能性の評価

2. **開発者視点**
   - テスト実装の実現可能性
   - テストフレームワークの選択
   - モック/スタブの設計
   - テスト実行時間の見積もり

3. **ユーザー視点**
   - 実際のユースケースがカバーされているか
   - Claude Code Agent Teamsのシナリオが十分か
   - エッジケースの洗い出し

4. **セキュリティ視点**
   - セキュリティテストの有無
   - ファジングテストの検討
   - 権限関連のテスト

## 特に注目すべきポイント
- TC-AGテストケース群（PTYプロキシ）のカバレッジ
- macOS固有のテスト制約への対応策
- CI環境での実行可能性

## 期待する成果物
- full-reviewレポート（新規ドキュメントを作成する場合は `docs/drafts/` 配下に配置すること）
- 不足しているテストケースのリスト
- テスト計画への改善提案

> **配置ルール**: この指示による新規ドキュメントは `docs/drafts/` 配下に配置すること。既存ファイルの編集は直接行ってよい。
